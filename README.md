# Decal Factory
Blender add-on for creating decals.  
Decal Factory can create decals from any material in your scene,  
and can also bake existing geometry into materials that can be used for decals.  
Decal Factory is designed to be as performant and noninvasive as possible.  
It does not use shrink wrap, or make changes to your existing materials.  
Decals can be moved/rotated/scaled/duplicated the exact same way you would adjust any other object.
